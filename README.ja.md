# csvmelt

横持ち（ワイド型）のCSVファイルを縦持ち（ロング型）にアンピボット（「メルト」）するためのブラウザベースのツールです。ブラウザ上で直接、横方向のデータを縦方向の整然データ（Tidy data）形式に変換できます。

## 機能

-   **インタラクティブなアンピボット:** 横持ちデータを縦持ち形式に変換します。固定の識別子として残す列を選択すると、残りの列は「メルト」され、キーと値のペアに変換されます。
-   **ドラッグ＆ドロップインターフェース:** CSVファイルをドラッグ＆ドロップするだけで開始できます。
-   **クライアントサイド処理:** すべての操作はブラウザ上でローカルに実行されます。データがサーバーにアップロードされることはありません。
-   **データクリーニングオプション:**
    -   すべてのセルの前後の空白をトリミング。
    -   桁区切り文字（カンマ）を削除して数値をサニタイズ。
    -   空行および末尾の空列を削除。
-   **エンコーディング対応:** Shift_JISやUTF-8などの一般的なエンコーディングを自動検出し、適切に処理します。
-   **カスタム出力:** 新しく生成される変数（キー）と値の列に任意の名前を設定できます。

## 使い方

1.  1つのCSVファイルをアプリケーションのページにドラッグ＆ドロップします。
2.  （オプション）ファイルをドロップする前に、必要なデータクリーニングオプション（空白のトリミング、カンマの削除など）にチェックを入れます。
3.  完全に**削除**する列を選択します。
4.  固定の識別子として**残す**列を選択します。それ以外のすべての列がアンピボット（縦持ち化）されます。
5.  アンピボットされた「変数」と「値」のデータに対する新しい列名を入力します。
6.  「変換」をクリックします。変換後のCSVファイルがダウンロードされます。

## 動作環境

-   モダンWebブラウザ（Chrome、Firefox、Safari、Edgeなど）。
-   JavaScriptが有効になっていること。

## データ / API

本プロジェクトでは、外部のデータやAPIは一切使用しません。すべての処理はブラウザ内で完結します。
